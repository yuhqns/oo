# 「咪挺」– 智慧會議紀錄助手 (物件導向軟體設計期末專題)

本系統可用於會議錄音、即時逐字稿、AI 摘要、心智圖產生、圖片內容分析，以及針對已儲存會議內容進行 RAG 問答查詢。

---

## 軟硬體專題內容概述

本系統結合瀏覽器前端與 Python 實作之後端服務（FastAPI + WebSocket）。主要包含四個核心工作流程：
1. **使用者與會議管理**：註冊、登入、建立資料夾，並透過 MySQL 資料庫管理不同會議紀錄。
2. **即時語音轉文字**：透過 WebSocket 傳送麥克風音訊片段，並使用本機 Whisper 模型進行即時辨識與 OpenCC 繁體中文轉換。
3. **AI 會議整理**：結合 LLM API 產生會議摘要、即時摘要、圖片分析結果，並利用 Markmap 渲染互動式心智圖，同時提供下次會議議程建議。
4. **歷史會議檢視與 RAG 問答**：針對已儲存會議內容（逐字稿、摘要與圖片分析）進行檢索增強生成（RAG）問答。

### 核心功能特色
- **資料夾式會議管理**：使用者可在 Dashboard 中建立資料夾並分類會議。
- **雙軌音訊輸入**：支援瀏覽器麥克風即時分段錄音轉錄，以及上傳既有音訊/影片檔案進行轉錄。
- **議程追蹤與討論狀態標記**：使用句向量模型比對逐字稿與預設議程主題，並以關鍵字規則初步判斷共識或爭議片段。
- **多媒體輔助分析**：可上傳會議截圖、白板或投影片，將 Vision API 分析結果納入會議紀錄。
- **心智圖音訊定位**：點擊含時間戳的心智圖節點，可直接跳轉播放對應的音訊片段。
- **Google Calendar 整合**：可依據 AI 建議的下次議程，透過 OAuth 授權自動建立 Google Calendar 事件。
